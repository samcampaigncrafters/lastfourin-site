How it works

  1. The list is hidden until you press start. Then the clock runs, and it keeps running if you leave the page.
  2. Type a full name. It locks in the moment it matches. Last name alone works too if you press Enter and nobody else on the list shares it.
  3. Every empty slot shows a hint: the season, team or game it belongs to.
  4. Ranked by how many you name, then by time left. Same list for everyone, so you can compare with friends.
